Usage: boru [OPTIONS] [COMMAND]

Commands:
  open  Open a new or saved chat room
  join  Join an existing chat room via ticket
  logs  Open the standalone log viewer for this profile
  help  Print this message or the help of the given subcommand(s)

Options:
      --secret-key <SECRET_KEY>
          

  -r, --relay <RELAY>
          

      --no-relay
          

      --no-dht
          Disable public and private room DHT discovery. mDNS, relay, tickets, and known addresses remain active

      --publish-direct-addresses
          Publish direct (public) IP addresses to the DHT for relay-free connectivity.
          
          Off by default (relay-only mode, which is privacy-preserving). When enabled, the DhtAddressLookup uses AddrFilter::unfiltered so direct addresses are published alongside the relay URL. Requires --no-dht to NOT be set. WARNING: This exposes your public IP address on the Mainline DHT.

      --data-dir <DATA_DIR>
          Directory for persistent identity and friend state. Chat and room history are kept in memory only. Defaults to the environment variables BORU_DATA_DIR or BORU_CHAT_DATA_DIR, or ~/.local/share/boru/

  -n, --name <NAME>
          

      --bind-port <BIND_PORT>
          [default: 0]

      --perf
          Enable performance instrumentation and print baseline report at exit

      --mcp
          Enable the MCP diagnostic server for AI-agent integration

      --enable-gui-test-actions
          Enable GUI test actions via MCP (requires --mcp)

      --mcp-bind <MCP_BIND>
          Bind address for the MCP diagnostic server (default: 127.0.0.1:8765)
          
          [default: 127.0.0.1:8765]

  -h, --help
          Print help (see a summary with '-h')
